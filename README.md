# BME Medical Imaging Workstation

A Streamlit-based biomedical image processing workstation for medical image analysis, DICOM viewing, image enhancement, filtering, tomography reconstruction, quality evaluation, and automated PDF report generation.

## Overview

This project is a medical imaging workstation developed in Python using Streamlit.  
It allows users to upload biomedical images, apply different image processing techniques, compare results, calculate quality metrics, and export processed images or a complete PDF report.

## Features

- Upload biomedical images such as PNG, JPG, BMP, TIFF, and DICOM
- DICOM viewer with metadata display
- Noise simulation tools
- Histogram enhancement methods
- Spatial domain filtering
- Frequency domain filtering
- Tomographic image reconstruction
- Before/after image comparison
- Image quality metrics including MSE, MAE, PSNR, and SSIM
- Export processed images
- Generate automated PDF reports

## Technologies Used

- Python
- Streamlit
- NumPy
- SciPy
- Matplotlib
- Pillow
- scikit-image
- OpenCV
- pydicom
